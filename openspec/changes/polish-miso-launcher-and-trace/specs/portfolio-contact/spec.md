# Portfolio Contact

## Purpose

Give portfolio visitors a direct way to start an email to the published address.

## ADDED Requirements

### Requirement: Both homepage Email me buttons open web compose

The hero and contact section SHALL open Gmail compose in a new tab with the configured portfolio address as the recipient. The footer SHALL expose a native mail link to the same address.

#### Scenario: Starting an email in a browser without a native handler

- **WHEN** a visitor activates either Email me button
- **THEN** the browser opens a Gmail compose destination addressed to the portfolio email
