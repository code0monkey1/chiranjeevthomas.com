# Portfolio Contact

## Purpose

Give portfolio visitors a direct way to start an email to the published address.

## ADDED Requirements

### Requirement: Both homepage Email me buttons use the visitor’s default mail client

The hero, contact section, and footer SHALL provide native mail links with the configured portfolio address as the recipient.

#### Scenario: Starting an email with a configured mail client

- **WHEN** a visitor activates either Email me button
- **THEN** the browser hands off the portfolio address to the visitor’s configured mail client
